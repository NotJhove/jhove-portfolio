Data Analytics

COVID Analysis

An interactive data analysis project exploring global COVID-19 trends.

This data analysis project investigates global COVID-19 trends, case distributions, and mortality rates across different countries from 2020 to 2021. This project is basically two projects combined into one, where the first part focuses on analyzing COVID-19 data using Excel and SQL, while the second part involves creating an interactive dashboard using Tableau to visualize the findings.

Data Exploration

Using SQL and Excel

View repository ↗

The dataset for this analysis was sourced from Our World in Data. Initial data validation and pre-processing were conducted in Excel, where the dataset was partitioned into two structured files (CovidDeaths and CovidVaccinations) to optimize query performance and streamline ingestion into Microsoft SQL Server.

Using SQL, I executed exploratory data queries-leveraging aggregate functions, CTEs, and joins—to isolate key mortality metrics across regions. The cleaned and structured query results were then exported to prepare the foundation for interactive visualization in Tableau.

FROM CovidDeaths
